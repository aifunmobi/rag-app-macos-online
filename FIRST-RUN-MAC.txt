RAG App macOS first run

Use this first:

  Double-click RAG Chat Setup.app

This is a native Swift macOS app. It opens its own setup window and streams
download/setup progress. Keep the app inside the rag-app folder.

If macOS shows this message for the app or setup-mac.command:

  Apple could not verify "setup-mac.command" is free of malware that may harm
  your Mac or compromise your privacy.

This is Gatekeeper blocking an unsigned downloaded app/script before the
installer can start. The app is ad-hoc signed, but it is not Apple Developer ID
notarized.

Reliable option:
  Open Terminal, type this with a trailing space:

    bash 

  Then drag setup-mac.command into the Terminal window and press Return.

Alternative:
  Open Terminal, change into the rag-app folder, then run:

    xattr -d -r com.apple.quarantine .
    chmod +x setup-mac.command "Start RAG (online).command" run.sh
    ./setup-mac.command

After the first successful Terminal launch, RAG Chat Setup.app should work. If
macOS still blocks it, run the same bash setup-mac.command command.
