How RAG Chat works

Add your documents, then ask questions in plain language. Answers are generated only from your files and show the exact sources they came from.

📥 Adding documents

  • Drag & drop files anywhere on the window, or click Upload files.
  • Or drop them into the input/ folder on disk — they’re picked up automatically.
  • Supported: PDF, Word (.docx), text, Markdown, HTML, and code files.
  • New and changed files are indexed automatically; you’ll see a glowing progress bar while they’re processed.

💬 Asking questions

  • Type in the box and press Enter (Shift+Enter for a new line).
  • Each answer lists its Sources — the file and chunk it drew from.
  • Copy buttons appear on every answer and code block.
  • Past chats are saved in the sidebar — click to reopen, ✕ to delete.

🔄 Re-index — and when to use it

Re-index re-scans the input/ folder: new or edited files get (re)processed, unchanged files are skipped, and files you deleted are removed from the index. It’s incremental — it doesn’t rebuild everything.

You usually don’t need it — drops and uploads index automatically. Use it when:

  • You changed files in input/ while the app wasn’t running.
  • You bulk-copied many files and want to be sure none were missed.
  • Files are on a network/mounted drive where auto-detection is unreliable.
  • The counts look out of sync and you want a full re-check.

🗂️ Index button & managing files

Click the Index label (top of the sidebar controls) to open the list of indexed files with their chunk count and time. Click the 🗑 trash icon next to any file to delete it — that removes it from both the input/ folder and the index. The index is reconciled automatically when you close the list.

⚙️ Model & theme

  • Model dropdown switches which local model answers (embeddings always use nomic-embed-text).
  • 🌙 / ☀️ toggles light / dark mode (remembered between visits).

Everything runs locally via Ollama. Your documents and chats never leave this machine. Data lives in data/rag.db.
